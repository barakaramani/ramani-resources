Design notes for the team
  1. The tool gives value first: the trader sees the real TZS cost of a supplier payment, in any of 165 currencies, before being asked for anything.
  2. The "Get a quote" button carries the amount and currency from the calculator, so ramani.io/apply/start opens with the order value already filled in.
  3. The newsletter offer is tied to the tool (weekly dollar rate) and asks for name and email only.
  4. On the live site, each step sends an event to the CRM (calculation done, quote clicked, newsletter joined) so follow ups start automatically.
  5. The live version needs a daily rate feed, compliance sign off on the quote copy, and Ramani's confirmed font, logo and full colour palette. Only the brand green (#04C401) was confirmed from ramani.io.
